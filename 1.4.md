# Problemas propuestos — 1.4

## 1. Crear la colección `articulos` en la base de datos `base1`

Eliminar la colección previamente y cargar luego 6 documentos utilizando la colección del problema propuesto anterior (1.3).

## 2. Imprimir todos los documentos de la colección `articulos`

```javascript
db.articulos.find()
```

**Resultado:** se muestran los 6 artículos cargados en el ejercicio 1.3.

## 3. Borrar los documentos de la colección `articulos` cuyo rubro son impresoras

Utilizar las dos sintaxis que permite MongoDB.

### Primera sintaxis

```javascript
db.articulos.deleteMany({rubro : 'impresora'})
```

**Resultado:**

```javascript
{
  acknowledged: true,
  deletedCount: 2
}
```

### Segunda sintaxis

```javascript
db.articulos.deleteMany({rubro : {$eq : 'impresora'}})
```

**Resultado:**

```javascript
{
  acknowledged: true,
  deletedCount: 0
}
```

> La segunda consulta se ejecuta después de la primera, por eso en la captura aparece `deletedCount: 0`.

## 4. Borrar todos los artículos que tienen un `_id` mayor o igual a 5

```javascript
db.articulos.deleteMany({_id : {$gte : 5}})
```

**Resultado:**

```javascript
{
  acknowledged: true,
  deletedCount: 2
}
```
