# Problemas propuestos — 1.2

## 1. Crear una base de datos llamada `blog`

```javascript
use blog
```

## 2. Agregar una colección llamada `posts` e insertar 1 documento

```javascript
db.posts.insertOne(
{
  _id: 1,
  nombre: "Pedro",
  tipo: "Critica"
}
)
```

**Resultado:**

```javascript
{
  acknowledged: true,
  insertedId: 1
}
```

## 3. Mostrar todas las bases de datos actuales

```javascript
show databases
```

**Resultado:**

```text
TestDB          8.00 KiB
admin           40.00 KiB
base1           140.00 KiB
blog            40.00 KiB
config          96.00 KiB
local           80.00 KiB
veterinariaDB   160.00 KiB
```

## 4. Eliminar la colección `posts`

```javascript
db.posts.drop()
```

## 5. Eliminar la base de datos `blog` y mostrar las bases de datos existentes

```javascript
db.dropDatabase()
show databases
```

**Resultado:**

```text
TestDB          8.00 KiB
admin           40.00 KiB
base1           140.00 KiB
config          100.00 KiB
local           80.00 KiB
veterinariaDB   160.00 KiB
```
